# Flash Library

Thousands of old Flash games (Miniclip, Newgrounds, Kongregate...) that play offline, on Windows, Steam Deck and Android.

**[Download the latest version](https://github.com/RamSwaggy/flash-library-releases/releases/latest)**: pick the file for your device under Assets.

- **Windows:** `Flash Library (Windows).zip`
- **Steam Deck / Linux:** `Flash Library (Steam Deck).zip`
- **Android:** `Flash Library (Android).apk`

No games are included. Open the app and use Get Games to download them from [Flashpoint Archive](https://flashpointarchive.org), a volunteer project that preserves web games.

The app checks this page for new versions and tells you when one is out.
